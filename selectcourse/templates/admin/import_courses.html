📋 文件格式说明

CSV / Excel 列名（支持中文表头）

字段必填说明
课程名称 / name✅课程名称
课程编号 / code✅唯一编号
授课教师 / teacher✅教师姓名
学分 / credits✅数值，0.5~10
容量 / capacity✅整数，1~999
学期 / semester✅如 "2026-秋季"
课程分类 / category_name可选，如 "通识课程""必修课程"等（须与系统中已有分类一致）
课程描述 / description可选
上课地点 / location可选
上课日 / day_of_week0=周一 … 6=周日（单时间段时使用）
开始时间 / start_timeHH:MM，如 08:00（单时间段时使用）
结束时间 / end_timeHH:MM，如 09:40（单时间段时使用）
时间段 / schedulesJSON 数组，支持多个时间段（优先）
